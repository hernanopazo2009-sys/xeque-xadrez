# Xeque

Um jogo de xadrez para navegador, feito para celular e computador. Jogue contra a máquina e instale o jogo na tela inicial como um app.

## Rodar localmente

Abra `index.html` no navegador. Para habilitar instalação e jogo offline, publique em um site com HTTPS (por exemplo, GitHub Pages).

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos para a branch `main`.
2. Nas configurações do repositório, em **Pages**, selecione **GitHub Actions** como origem de publicação.
3. O workflow em `.github/workflows/pages.yml` publicará o site. O endereço aparecerá na página **Pages** do repositório.

## Instalar no celular

- **Android:** abra o endereço publicado no Chrome e use **Instalar app** ou **Adicionar à tela inicial** no menu.
- **iPhone:** abra o endereço no Safari, toque em **Compartilhar** e escolha **Adicionar à Tela de Início**.

Depois da primeira visita, o jogo pode abrir sem conexão.
